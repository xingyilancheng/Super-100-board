# 百数板乐园 · 数字小达人

一款给小朋友玩的**百数板（Hundred Chart）闯关游戏**。棋盘居中，可切换实木 / 亚克力 / 马卡龙 / 星空四种材质；左侧是账户、积分、关卡地图与设置；右侧是 10 个候选数字方块。点对了数字，方块会带着飞入尾迹落进棋盘；点错了，方块会左右摆几下提醒你再想想。

纯前端实现（HTML + CSS + 原生 JS），零依赖、无构建步骤，双击 `index.html` 就能玩，也可以打包成 Windows / macOS / Linux 桌面应用。

## 一、网页上试玩

方式 A：直接用浏览器打开 `index.html`（无模块化加载，`file://` 也能跑）。

方式 B：起个本地服务器（推荐，行为和打包后一致）

```bash
npm run web          # 默认 http://localhost:5173
node tools/serve.mjs 8080   # 也可以指定端口
```

## 二、打包成桌面应用

```bash
npm install          # 首次会下载 Electron，约 100MB，请耐心等待
npm start            # 先以桌面窗口方式预览
npm run pack         # 只生成免安装目录 dist/win-unpacked
npm run dist         # 生成安装包：NSIS 安装程序 + 单文件免安装版
```

> Electron 和 electron-builder 的二进制默认从 GitHub 下载，国内网络容易卡住或报 `getaddrinfo ENOTFOUND github.com`。
> 项目里已带 `.npmrc`，把两者指向 npmmirror 镜像；如果所在网络能直连 GitHub，删掉 `.npmrc` 即可。
> 也可以在单次安装时临时指定：
>
> ```bash
> ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
> ```

产物在 `dist/`：

| 文件 | 说明 |
| --- | --- |
| `百数板乐园-安装包-1.0.0.exe` | NSIS 安装程序，可选安装目录，自动建桌面/开始菜单快捷方式 |
| `百数板乐园-1.0.0-x64.exe` | 单文件免安装版，双击即玩 |
| `win-unpacked/` | 免安装目录版 |

macOS / Linux 请在对应系统上执行 `npm run dist`（`package.json` 里已配好 dmg 与 AppImage 目标）。

## 三、玩法说明

### 关卡地图（25 关，由易到难）

| 章节 | 关卡 | 训练目标 |
| --- | --- | --- |
| 第一章 · 初次见面 | 1–5 | 认识 1–100 的位置：单个数字、少量数字、一行连续、散落分布、每行一个 |
| 第二章 · 上下左右 | 6–10 | 掌握“右 +1、下 +10”的规律：整行、整列、相邻行、连续小分队、十字邻居 |
| 第三章 · 跳来跳去 | 11–15 | 跳数（+2 / +5 / +10）、双行同步跳数、混合规律 |
| 第四章 · 小侦探 | 16–20 | 成块缺失的推理补齐：缺角、3×3 空洞、最后一行、打乱数字、左右两列 |
| 第五章 · 百数大师 | 21–25 | 综合挑战：随机 10 格、棋盘斜纹、中间大块、上下配合、终极连片 |

每一关的题目由固定随机种子（`关号 × 7919 + 13`）生成 —— 每次打开同一关，题目都一样，方便反复练习；不同关卡各不相同。候选区始终给出 **10 个数字方块**（正确答案与干扰项混排），点中棋盘上的空格还能切换目标格。

### 计分与星级

- 放对一个数字：**+10 积分**，每连续放对 3 个额外 **+5**
- 放错一个数字：**−3 积分**，连击清零，方块左右摆动；每错 3 次会自动闪光提示正确方块
- 用一次提示：**−5 积分**（积分不足时最多扣到 0）
- 通关：**+20 积分**，零失误 **+10**，全程未用提示 **+5**
- 星级：零失误 ★★★，错 1–2 次 ★★，其余 ★
- 称号：按累计通关数从「数字新星」一路升到「百数板大师」

进度、积分、星星、昵称、头像和设置都存在浏览器 `localStorage`（键名 `hundred-board-save-v1`），关掉再打开继续玩。设置里的「重置进度」只清空积分 / 星星 / 关卡，昵称、头像和材质偏好会保留。

### 四种棋盘材质

| 材质 | 风格 | 上色规则 |
| --- | --- | --- |
| 实木 | 原木边框 + 奶白数字块 | 统一暖色 |
| 亚克力 | 磨砂玻璃 + 高光斜纹 | 按**列**渐变（每列一色） |
| 马卡龙 | 奶油底色 + 糖果色 | 按**行**配色，粉橘到紫 |
| 星空 | 深蓝星点 + 霓虹数字 | 按**行**配色，蓝紫微光 |

### 动画与音效

- **飞入尾迹**：点击正确方块后走一条抛物线，飞行中留下残影与星尘，落点扩散光圈并炸出星星
- **错误摆动**：点错的方块左右摆动数次并泛红，同时冒出 `-3`
- 音效由 WebAudio 实时合成（点击、拾取、正确、错误、提示、通关），不依赖任何音频文件
- 设置里可关闭音效，或把动画切到「精简」模式（低配设备更流畅）

## 四、隐私与离线

游戏不联网、不收集任何数据，所有进度只保存在本机。字体已内联进 `css/fonts.css`，图标与音效均为本地资源，断网也能完整运行。
